# Griya Panel — Showroom 3D

Mockup website jual beli wall panel dan plafon PVC dengan showroom 3D yang bisa dijelajahi langsung di browser.

## Fitur
- Showroom 3D (Three.js): jalan dengan WASD / tombol panah, seret untuk melihat sekeliling, tombol joystick di HP
- 8 motif wall panel di dinding dan 4 zona plafon PVC di langit-langit
- Klik panel untuk melihat spesifikasi, harga, dan kalkulator jumlah lembar (termasuk cadangan potong 10%)
- Katalog dengan filter dan tombol "Lihat di showroom"
- Daftar penawaran yang bisa disalin untuk dikirim via WhatsApp

## Menjalankan
Cukup buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/root`).

Harga, nomor WhatsApp, dan motif adalah data contoh. Tekstur dibuat secara prosedural dan bisa diganti dengan foto produk asli.
